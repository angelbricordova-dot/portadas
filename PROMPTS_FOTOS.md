# Fotos para las revistas: generar en ElevenCreative (Image)

Tu plan Creator no permite generar imágenes por API (exige Pro), pero sí desde la web con tus créditos.

1. Entra en ElevenLabs → **ElevenCreative → Image**.
2. Elige un modelo **fotorrealista** (Nano Banana Pro / Gemini, Seedream o GPT Image) y usa **el mismo para las 25**.
3. Para cada foto: pega el prompt completo, pon la **proporción** indicada y genera. Si la web no tiene esa proporción exacta, usa la más parecida (yo recorto al montar).
4. Si sale rara (manos deformes, letras o números, caras de cerca, aspecto plástico o de videojuego), regenera.
5. Descarga y **renombra exactamente** con el nombre indicado (la extensión .png/.jpg/.webp da igual).
6. Mete todas en **un solo ZIP** y súbelo al chat. Puedes mandarlas por tandas (una revista cada vez).

Mira cuántos créditos gasta la primera imagen: con 100.033 debería sobrar.
